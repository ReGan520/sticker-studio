# 角色设计与定稿

## 使用真实人物或动物

从照片观察剪影、头身比例、五官间距、发型或毛色分区。提取两至四个在小尺寸仍清晰的识别点。人物可以是圆框眼镜、侧分轮廓和偏垂的眉形。动物可以是左耳缺角、额头三道虎斑和右前爪白袜。确认左右以角色自身或画面为基准，避免镜像时标记换边。

允许夸张的部分单独写清，如嘴可以张得很大、身体可以挤扁，但头顶花纹和关键配件必须稳定。原照片过暗或遮住特征时，用能辨认的角度完成首张；只有遮挡特征会改变整体方案时才补问。

## 从零生成原创 IP

从角色的性格矛盾或口头禅切入。例如「嘴硬、却会偷偷帮忙的小企鹅」应在动作里有明确的嘴硬姿态和偷偷帮忙的道具。先出两个能靠剪影区分的方向，让头身比例、主形体、配件至少改变两项。确定方向后生成干净的正面或三分之四参考图，再用大笑、嫌弃和崩溃三种反差表情检查辨识度。保留表现最稳定的定稿。

## 记录与续作

角色档案跟随项目。在角色档案里记录角色名、风格、标准图路径和识别点，并按需补齐主色、体型比例、典型神态与允许变化。用 `reference_revision` 记录角色定稿版本，`version` 表示数据格式版本。需要背面或侧脸姿势时补角度参考。每张新表情同时使用定稿图和识别点文字，挑选已通过审核的表情作为追加示例。改外观时记录新版本和改动，原项目仍引用旧版。项目 `pack.json` 的 `character` 指向角色 JSON，`reference` 和 `expression_sheet` 相对于角色 JSON 的所在目录。
