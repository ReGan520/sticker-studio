# GIF 制作

## 先按这张表情设计动作

逐张看参考图里现有的神态、视线、身体朝向、手势和道具，结合这张表情的聊天用途，写下「起始状态 → 情绪或肢体如何变化 → 最清楚的一拍 → 如何收尾」。每一拍指出**角色哪一部分变了**，例如眼睑压低、嘴由抿紧转为张开、肩膀耸起、前爪离地。台词一样时也要按不同角色和原图重新设计。

每条先确定一个主情绪，写明由哪些部位传达，再写清肢体动作如何配合。例如「勉强答应」靠半垂眼睑、瞳孔斜看和抿嘴传达语气，双爪摊开表现让步。若把关键词遮掉仍看不出主情绪，先强化最有用的眉眼、嘴形或姿势。

| 表情及原图线索 | 可画的动作 |
|---|---|
| 「不理解」，猫歪头盯镜头 | 眼睛先追向旁边 → 耳朵竖起、眼睛睁圆 → 脖子带动头再歪一点、前爪慢慢抬起 |
| 「笑死」，人物抿嘴努力憋笑 | 嘴角抽动 → 眼睛眯起、肩膀抬高 → 捂嘴破功，肩膀跟着笑声颤动 |
| 「收到」，人物手还垂着 | 目光转向对方 → 屈肘抬手、下巴点下去 → 手掌举定，眼睛回看 |
| 「不想上班」，动物趴在桌边 | 眼皮垂下 → 前爪往前伸、肩部压低 → 下巴落到爪上，停在趴平的终态 |

## 分层路线

分层适合辅助动作，也适合分别操控眼、嘴、头、手等有独立素材的部位，只要最终能看到角色的表情或姿势变化。整张角色图的摇晃、缩放、平移，以及符号弹出可以增强节奏。仅在用户明确指定时，才把这类效果单独作为成品。各层使用同一注册画布和对齐方式，脚本先适配画布，再绕中心旋转或缩放并应用位移。位移单位为导出像素，`x` 向右、`y` 向下。

## 关键姿势路线

适合眨眼、张嘴、转身、挥手、摔倒等角色本身改变形状或姿势的动作。这类请求默认使用逐帧路线，补画关键姿势之间实际会经过的姿势。原有分层补间可用来处理符号和道具的辅助运动。

1. **先画并验收情绪最清楚的一帧。** 用约 64–96 px 的无字预览检查神态和手势。确认眉眼、嘴形或关键动作在聊天尺寸下足够清楚，再以这一帧作为相邻帧的参考。若只读出动作、读不出情绪，先改负责表达的部位。
2. **沿动作轨迹补画独立帧。** 简单完整的循环可先以 6–8 个不同画面规划，按实际复杂度增减。优先补起势后的第一段、眼神与手势错开的中间拍、收势和接回起姿的过渡。例如摊爪可依次画起姿、先移视线、爪子抬到一半、摊开、眼神落回侧面、收爪过半和回到起姿。复用帧用于回程，停顿用帧时长表达。统计不同画面时去掉重复帧。
3. **逐张或分批出图，保持机位和识别点。** 单张分镜图的格数由各姿势的清晰度和留白决定。还缺过渡姿势时，用已验收的角色参考和相邻帧继续补画。所有帧用同尺寸透明画布，以脚底、身体中心或固定道具对齐，避免每帧按轮廓自动居中造成漂移。
4. **逐帧挑错，再看实际播放。** 放慢检查肢体轨迹连续、角色体量稳定、脸和配件没有换边。检查正常速度下表情和停顿是否读得懂。若某段仍跳，标出两张相邻帧并补画具体姿势，再重建这个表情。GIF 循环时检查收势接回起势，抬起和落下动作可复用可自然逆放的中间姿势。需要眨眼和转身等真实变化时，淡入淡出和整图位移不能替代补画。

若有连续视频素材，可检查角色、机位和边缘稳定性，再提取为同画布的透明帧。若当前图像工具无法产出可用的中间姿势，保留已通过的帧并指出仍缺哪几拍。

## 循环和导出

无限循环时从最后一拍逐帧看回第一拍，注意位置、速度和轮廓衔接。播一次时检查终态足够清楚。静态预览取最有表现力的一拍。GIF 只有索引色和硬透明，查看浅、深背景下的轮廓和调色板稳定性。平台尺寸或体积吃紧时先简化细碎纹理，再尝试降低颜色数或减少次要帧，每次用实际导出文件复看。

## 时间轴配置

在 `pack.json` 中，`kind: "gif"` 的表情只选 `frames` 或 `layers`。逐帧路线的每帧有 `source` 和 `ms`，所有源图尺寸一致。分层路线的每层有 `source` 和 `poses`，各层按从底到顶排列，所有层每一拍的时长相同。每拍可填 `x`、`y`、`angle`、`scale` 和 `opacity`（0–1）。这些配置描述时间轴上的姿势。在某一拍加 `"tween": "ease-in-out"`，脚本会在该拍时长内补到下一姿势，按约 30 ms 采样，起止减速，同时保持总时长。匀速移动用 `"linear"`。省略 `tween` 时保持当前姿势，适合预备或表情定格。无限循环的末拍也可以补到首拍，一次播放的末拍保持最终姿势。时长以 10 ms 为步进，至少 20 ms。用 `loop: "repeat"` 无限循环，`loop: "once"` 播放一次。

```json
{
  "id": "peek",
  "kind": "gif",
  "meaning": "偷看",
  "loop": "repeat",
  "layers": [
    {
      "source": "source/peek.png",
      "poses": [
        {"ms": 180, "x": -8, "angle": -3, "tween": "ease-in-out"},
        {"ms": 220, "x": 8, "angle": 3},
        {"ms": 180, "x": 8, "angle": 3, "tween": "ease-in-out"}
      ]
    }
  ]
}
```


## 出片门槛

对照实际导出的 GIF，忽略配字、符号和特效，指出起势、中间帧和高潮的表情或姿势分别有什么变化。如果只看到同一个轮廓换位置、角度或大小，退回补画，或者拆出有独立状态的部件。帧数和平滑度只能用来衡量节奏，不能代替内容验收。缺少可用动作帧时，保留原画及已通过的帧，指出缺的姿势，把当前结果标为试稿。整套先用一条有清楚动作变化的 GIF 锁定质量，再逐条走同样的验收。
