# 成品验收

用整套预览寻找重复动作和风格漂移，再逐张打开实际交付的 PNG 或 GIF。用 64 px 左右验证基本情绪，用目标平台尺寸核对文字和小图标。浅底、深底各看一次。

| 检查 | 通过标准 | 常见修正 |
|---|---|---|
| 角色 | 核心轮廓、标记位置、配色跨图一致，夸张姿势仍能认出 | 对照定稿重画少数帧 |
| 聊天语义 | 小尺寸能读出主情绪，动作与语气一致，相邻表情有明确区别。动图补画过渡帧前，先看约 64–96 px 的无字高潮帧 | 强化承担情绪的眉眼、嘴形或手势，必要时收紧构图 |
| 字幕 | 字句与标点准确、大小舒适、与脸和手势分离 | 调字形、描边、位置或换行 |
| 透明边缘 | 主体完整，四周无裁切、杂点、明显底色残边 | 返工透明源图、增大安全边距 |
| 动图 | 角色的眉眼、嘴或肢体确实发生与聊天语义相关的变化，起势、高潮、收势和循环接回处衔接自然，关键动作读得出来，无残影、闪边、误删停顿或颜色跳闪 | 调整时长、锚点、帧图或调色板 |
| 微信配套 | 缩略图和主图一一对应，横幅、封面、图标适合各自位置和尺寸 | 换清晰关键帧，单独重构配套图 |

确认过样张只代表制作方向可以批量展开。整套导出后还要验收每一张。报告具体失败 ID 和失败发生的尺寸、背景或帧位，解决后只重建关联表情，并更新项目预览和技术校验。
