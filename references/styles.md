# 风格预设

| 预设 | 形体和表情 | 线条与材质 | 缩小检查 |
|---|---|---|---|
| 软萌 Q 版 | 大头小身、圆形剪影、五官集中，夸张腮帮和短手势 | 圆润外轮廓、低到中饱和主色、至多一层柔和阴影 | 腮红、眼睛和嘴各自清楚 |
| 手绘线条 | 先抓有辨识度的剪影，五官位置自然，允许适量不规则 | 有压感的外线、内线更细，大块平涂，纹理留给少数区域 | 缩到 64 px 后，细碎笔触可以丢失，手势和眉眼仍完整 |
| 夸张漫画 | 单一方向的姿势张力，张口、歪头或挤脸承载情绪 | 粗外线、疏密分明的动作线、高对比色块 | 表情和身体动作比速度线更突出 |
| 3D 卡通 | 保留清楚的头身比例和表情轮廓，用圆润立体形体表现手势 | 柔和主光与轮廓光，局部光泽区分材质，阴影收在角色轮廓内 | 眼、嘴、手势和躯干在小尺寸下仍能分清 |
| 黏土 3D | 易读的块状体积、夸张眉眼和手势 | 哑光、柔光、控制颗粒和阴影，保留透明背景 | 手臂与躯干亮度有差异，侧脸仍能认出 |
| 像素 | 先决定低分辨率像素网格，用大形状表现主要姿势 | 有限调色板、整齐像素边缘，按语义分块 | 用最近邻放大源图，检查导出后是否出现模糊边和不规则像素 |
| 写实照片 | 保留真实面部或动物体态，让视线、姿势和瞬间表情传达情绪 | 自然光、真实皮肤或毛发质感，用干净透明抠图保留发丝和胡须 | 缩小后主体和情绪清楚，深浅背景下边缘无残底 |

「手绘」「像素风」「3D卡通」可直接作为选择。写实照片可用于照片参考或从零生成写实形象。若要公开投稿，按实际画面和当前表单选择类别。

风格试稿使用同一参考、同一个动作和相近的画面占比。每个方向一张即可，放在浅色和深色背景上比对。用户有风格参考图时，从中提取材质、笔触、用色等属性，主体识别点仍以角色档案为准。


## 夸张度

| 档位 | 生成要求 |
|---|---|
| 自动 `auto` | 按聊天语义和风格决定。写实优先自然表演，喜剧漫画可放大一个主要动作。 |
| 克制 `subtle` | 保留自然比例，通过眼神、眉毛、嘴角或单一小动作表达。 |
| 明显 `strong` | 强化一个主动作，例如抬肩缩脖或瞪大双眼，搭配一处辅助反应。 |
| 极致 `extreme` | 将主动作推到喜剧高潮。卡通可用挤压拉伸，写实用可实现的强表情、姿态和镜头透视。 |

角色的识别点优先于档位。GIF 的夸张度主要体现在高潮帧，起势和收尾留出幅度差。

## 构图

| 选项 | 画面范围 |
|---|---|
| 自动 `auto` | 表情靠眉眼读懂时选大头，靠手势选半身，靠腿脚、全身姿态或大动作选全身。 |
| 大头 `head` | 以完整头部为主，保留发型、耳朵和头饰的识别轮廓。 |
| 半身 `half-body` | 头到腰附近，完整保留表达动作的手、前爪或道具。 |
| 全身 `full-body` | 从头到脚，必要时包括耳尖、尾巴和动作留白。 |

构图在生成原画和动作帧时执行。用户指定时优先采用。GIF 预先为最大动作留出边距，各帧共用同一镜头和主体锚点。
