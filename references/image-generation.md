# 生成无字原画

优先调用会话中可用、能接收角色参考和输出透明位图的图像工具。根据当前环境提供的接口传入真实参考图片，确认工具收到了图片。生成透明表情时要求原生 alpha、完整剪影、主体四周留白和干净边缘；动图帧预留最大动作幅度需要的画布。表情字幕交给后续排版。

每张图的生成说明写清以下内容。

- **交付画面**。静态、动画第几拍、或微信配套图。若为动画帧，说明必须沿用的镜头和主体锚点。
- **参考图的作用**。先说明哪张是定稿角色、哪张是风格或动作参考。角色与风格特征有冲突时保留识别点。
- **表情的可见证据**。写出肩、手、眉、眼、嘴各自需要的具体变化。可以直接用「肩抬高，双手停在半空，眉头紧锁」表达僵住。
- **夸张度和构图**。把档位改写成具体的表情幅度、身体姿势和入镜范围，例如「明显＋半身」写成眉毛挑高、一手举到肩侧、镜头到腰且手掌完整入镜。
- **画布和边缘**。避免裁耳、裁尾或变换视角，给字幕留白。使用透明背景时避免大面积虚化光晕和不必要的接地阴影。

样张不通过时每次改一个明确的视觉问题，尽量用定向编辑保住已通过的特征。成功源图按表情编号保存。用工具进行编辑时遵照其参考图片传递方式，使用当前可访问的参考文件。工具只接受当前会话图片时，按接口先传入所需图片。

没有可用的图像工具时，仍可构建用户已有的源图。保存尚缺的图像任务、画面提示和预期路径，明确标出待补资产，避免把草稿状态交成成品。
