# 表情包制作室

`sticker-studio` 可以把照片、角色图或一句创意做成透明 PNG、GIF 或整套聊天表情。它也能保存角色档案供以后续作，以及打包微信表情开放平台需要的投稿素材。

## 快速上手

在 Codex 中选择「表情包制作室」或输入 `$sticker-studio`，上传参考图，再用一句话说明你想做什么。如果当前会话没有列出这个 Skill，可以让 Codex 读取本目录的 [SKILL.md](SKILL.md) 并按它执行。

> $sticker-studio 把这张猫图做成「我就看看」。写实照片风，大头，透明 PNG，再给我一张无字版。

只有图片也可以开始。上传图后说「帮我想几个表情」，Skill 会根据眼神、姿势、道具和取景，给 **3–5 条带编号的创意**，标出最推荐的一条，并说明动作、风格、构图和 PNG/GIF 格式。可以回「选 2」「做 1 和 3」或「选 2，换成无字」。选定后再出图。说「你直接决定」可以让 Skill 自选方向出样。

## 按场景使用

| 玩法 | 可以直接复制的指令 |
|---|---|
| 人物照片转表情 | 上传自拍。「保留我的圆眼镜和短发，做一张手绘半身『收到』，举手答应，夸张度克制。」 |
| 宠物或动物 | 上传宠物图。「保留左耳缺口和白脚，做『不想上班』，3D 卡通、全身、明显夸张，要能看出它在赖着不走。」 |
| 用已有角色或 IP | 上传角色图或设定图。「沿用我提供的角色和配色，做一张像素风『马上到』，画它背着包跑，保留帽子。」 |
| 从零做原创 IP | 「设计一只嘴硬但很好哄的小乌云。先给两种轮廓方案，定稿后用大笑、嫌弃、崩溃试表情，再保存角色档案。」 |
| 比较画风 | 「用同一张猫图和『搞定』的动作，分别做手绘和 3D 卡通样张。我看完再选整套用哪个。」 |
| 做日常主题套装 | 「用这张猫图做 8 张同事聊天表情，覆盖收到、催进度、拒绝、庆祝和下班。静态为主，选两张最适合动起来的做 GIF。先给选题和代表样张。」 |
| 只定了形式，想让 Skill 提创意 | 上传图。「想做大头 GIF，先给我几个可选方向。」 |
| 已有无字原画，只做排版 | 上传透明原画。「保留原画，上方配『马上回』，导出透明 PNG 和无字版。」 |
| 跨套续作 | 提供上一套的角色档案和参考图。「用上一套的小乌云做春节篇，保留闪电眉和黄雨靴，给我 6 张新表情。」 |
| 单张改字、换动作或补做 | 提供原项目。「第 2 张换字为『下次一定』，第 4 张改成转身走开，再新增一张『等等我』。」 |
| 微信聊天自用 | 「做两张 320×320 的透明 PNG 和一张循环 GIF，用于聊天自用。」 |
| 微信表情开放平台投稿 | 「做一套供微信表情开放平台投稿的原创卡通专辑。我会提供上传表单规格，请产出配套素材、文案、校验报告和 ZIP。」 |

已有明确台词、情绪或动作的单张，可以直接试做。制作整套或新 IP 时，会先确认角色与选题。套装含 GIF 时也会预览代表性动图，再批量生成。

## 风格、夸张度、构图怎么选

| 选项 | 可用值 |
|---|---|
| 风格 | **3D 卡通**、**手绘线条**、**像素**、**写实照片**、软萌 Q 版、夸张漫画、黏土 3D，也可以上传风格参考图 |
| 夸张度 | **自动**按聊天语义和风格决定；**克制**靠微表情；**明显**强化一个主动作；**极致**把主动作推到喜剧高潮 |
| 构图 | **自动**按动作决定；**大头**突出眉眼和头部特征；**半身**保留手势；**全身**展示腿脚、尾巴或整套动作 |

三个选项可以自由组合。整套可以设默认值，再给单张例外，例如「整套手绘、明显夸张，构图自动；第 3 张只用大头、夸张度克制」。给了原话时，配字会沿用原文。可以指定配字在上方或下方，也可以同时要有字版和无字版。 [风格和画面规则](references/styles.md)

## GIF 怎么玩

建议把台词和角色表演一起说清楚，例如「做『笑死』，先抿嘴憋笑，再眯眼、抬肩、捂嘴破功」。默认会为每条 GIF 设计表情或姿势变化，整体位移和摇晃只用来加强节奏。

- **小动作**适合分层合成，例如发抖、点头、问号弹出。可以说「让猫先停半拍，左右抖三下，回到原姿势，无缝循环」。分层动作支持缓动补间，适合减轻姿势硬切和突停。
- **明显的姿势变化**默认走逐帧绘制并补画中间姿势，例如从探头到溜走。可以说「先探头，眼睛一亮，再跑出画面，只播放一次」。
- **已有姿势图或部件图**可以直接合成。上传同尺寸的透明素材，说明顺序、每拍停留多久、需要循环还是播放一次。也可以让 Skill 选一帧做静态预览。
- **动图返工**可以只改一处，例如「最后一帧多停 300 ms」「把第 3 帧换成闭眼」「配字删掉，再出无字 GIF」。

用导出的 GIF 和浅深底预览检查透明边缘、动作、字幕、前后衔接以及缩小后的可读性。 [动作时间轴与素材要求](references/gif-production.md)

## 微信投稿怎么玩

聊天自用可以直接用通用 PNG 或 GIF。准备开放平台专辑时，告诉 Skill 投稿类别、是否做静态或动态套装，以及当前上传表单的要求。有表单截图时可以一起上传。真人肖像或已有 IP 用于公开投稿时，需要按对应类别确认授权和资料要求。

通常会交付编号主图、对应缩略图、详情横幅、封面、面板图标、专辑介绍与逐张含义词、校验报告和 ZIP。可以指定 GIF 中哪一帧做缩略图，也可以给专用缩略图。表单要求赞赏素材时，可附带引导图、致谢图和文案。

没拿到当前表单时，可以先按草稿规格打包。正式投稿前按实际上传字段核对，审核与提交在平台完成。 [微信配置和导出说明](references/wechat.md)

## 交付文件和复用方法

| 文件 | 用途 |
|---|---|
| `pack.json` | 每张表情的编号、文字、素材、动效和导出设置 |
| 角色档案、参考图、`source/` | 续作、换字、重建和局部替换所需材料 |
| `export/*.png`、`export/*.gif` | 可直接使用的表情成品 |
| `export/preview.html`、`contact-sheet.png` | 打开 HTML 查看动图及浅深色底，联系表用于扫一眼整套静态画面 |
| `export/validation.json` | 文件层面的格式、尺寸、透明度、GIF 帧和循环等检查 |
| `export/wechat/` | 微信投稿专用素材、文案和 ZIP |

要继续出下一套，把角色档案和参考图一起给 Skill。要换字或补做单张，提供完整项目更方便，因为其中已有原画和时间轴。

随项目提供三组可打开的样例。 [人物照片转漫画](../样张验收/人物静态/export/preview.html) · [橘猫循环 GIF](../样张验收/橘猫动图/export/preview.html) · [原创乌云续作](../样张验收/原创IP/export/preview.html)

## 已有原画时手动构建

从本 Skill 目录运行，先在所用的 Python 环境安装依赖。项目需有 `pack.json` 和对应源图。可以从 [最小静态示例](SKILL.md#最小静态项目) 开始，并查看 [项目配置](schemas/pack.schema.json) 和 [角色配置](schemas/character.schema.json)。

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/sticker.py build "/path/to/表情包项目"
python3 scripts/sticker.py build "/path/to/表情包项目" --id sticker-02
python3 scripts/sticker.py check "/path/to/表情包项目"
python3 scripts/sticker.py wechat "/path/to/表情包项目"
```

脚本用已有素材排版和合成。创作新原画或动作帧时，由会话中的图像工具生成。中文字体缺字或找不到字体时，可以通过 `pack.font` 指定项目内的字体文件，TTC 用 `font_index` 选字族。 [配字说明](references/expression-planning.md)
